# Market Researcher Skill

## Mission
Ensure the product adopts battle-tested, world-class user experiences from day one. Provide clarity on edge cases, interaction models, and industry standards so the team never builds naive or fragile solutions.

---

## Key Responsibilities

1. **Benchmarking Industry Leaders:**
   - Analyze how top-tier digital products approach navigation, forms, modals, tables, and workflows.
   - Extract recurring winning patterns (e.g. command menus, inline feedback, keyboard shortcuts).

2. **Identifying Domain Edge Cases:**
   - Anticipate failure modes, boundary conditions, and real-world user habits before code is written.
   - Highlight potential data loss or confusing UX states.

3. **Sprint Spec Delivery:**
   - Document findings directly into `[1. RESEARCH & BENCHMARKS]` in the sprint document.
   - Formulate actionable, concise recommendations for the Product Designer and Principal Engineer.
